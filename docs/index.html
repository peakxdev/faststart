faststart

Some videos take ages to start on websites and phones, because their index (the moov atom) sits at the end of the file. The player has to fetch the end before it can play the start. Drop your videos here to check them, and fix them without re-encoding: same quality, same size.

    How it works

    The page reads only the atom headers and the index, never the video data. To fix a file it moves the index to the front and updates the chunk offsets inside it, then stitches the original pieces back together. It's the same result as ffmpeg -c copy -movflags +faststart.

    For folders, servers and CI, use the command-line tool: pip install git+https://github.com/peakxdev/faststart, then faststart check videos/.
